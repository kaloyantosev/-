# IRIS Pay | Електронно подписване на документи

Професионална, минималистична и изчистена система за интерактивно двустранно попълване и електронно подписване на:
1. **Рамков договор за извършване на плащания чрез услуга по иницииране на плащания** (чл. 4, т. 7 и 8 от ЗПУПС);
2. **Приложение № 1 – Такси и комисиони** (Интеграционна такса 0 EUR, Месечна такса 0 EUR, Такса за иницииране 0.49%);
3. **Общи условия на „Айрис Солюшънс“ АД** (За прочит и запознаване).

---

## Основни функционалности

- **Двупанелен интерфейс (Split-Screen)**:
  - Вляво: Интуитивен формуляр за данни за Търговеца (Фирма, ЕИК, Адрес, Представляващ, Банка, IBAN, Контакти).
  - Вдясно: Интерактивен преглед на документите на реален A4 формат с моментална синхронизация в реално време (Live Sync).
- **Интеграция с Електронен подпис**:
  - Рисуване на саморъчен подпис през тъчскрийн или мишка;
  - Въвеждане с калиграфски и курсивни шрифтове;
  - Квалифициран електронен подпис (КЕП / Evrotrust / B-Trust / Инфонотари) с генериране на сертификат, времеви печат и криптографски SHA-256 хеш;
  - Качване на файл с подпис/печат.
  - Полагане на подписа едновременно върху Рамковия договор и Приложение 1.
- **Преглед на Общите условия**:
  - Пълен оригинален текст на Общите условия на „Айрис Солюшънс“ АД за прочитане преди финализиране.
- **Потвърждение и Изпращане**:
  - Модален прозорец с официално съобщение:
    > *„Успешно изпращане. Екипът на IRIS Pay проверява документите и ще ви извести щом бъдат подписани.“*
- **Експорт / Печат**:
  - Оптимизиран CSS за печат и сваляне на документите директно в PDF формат.

## Локално стартиране

Сайтът е изграден като бърз, напълно автономен статичен уеб проект (HTML5, CSS3, Vanilla JS).

Можете да го отворите директно във всеки браузър или да стартирате локален HTTP сървър:
```bash
python -m http.server 8080
```
И отворете в браузъра: `http://localhost:8080`

## Публикуване в GitHub Pages

Тъй като проектът не изисква компилация или външни зависимости:
1. Инициализирайте git хранилище в папката:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of IRIS Pay Document Signing Portal"
   ```
2. Свържете с вашето GitHub хранилище и го качете:
   ```bash
   git remote add origin https://github.com/<вашето-потребителско-име>/<име-на-хранилището>.git
   git branch -M main
   git push -u origin main
   ```
3. Влезте в **Settings -> Pages** в GitHub и изберете клон `main` и папка `/(root)`. Вашият сайт ще бъде активен онлайн след няколко секунди!
